# review-starter

다른 직원이 실제 운영 중인 `review` 구조와 GitHub Actions 자동화를 출발점으로 복사해 자신의 사건 작업공간으로 독립 운영하기 위한 starter 저장소입니다.

처음 복제하거나 전달받았다면 먼저 [`STARTER_GUIDE.md`](STARTER_GUIDE.md)를 확인하세요. Actions 초기 점검, OneOCR cache, 선택적인 `PURGE_TOKEN`, `m1`과의 연계 방식은 해당 안내문에 정리되어 있습니다.

> 이 저장소는 업무지침의 공통 표준이 아니라 시작용 작업틀입니다. 필요한 부분은 자유롭게 수정·삭제·추가하여 사용하세요.
